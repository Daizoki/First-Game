# Examenul (The Godborn Exam)

Primul joc din universul „Coborârea”: un roguelite pe ture cu cărți, făcut în Godot 4.

- Reguli de lucru: [`CLAUDE.md`](CLAUDE.md)
- Design: [`docs/DESIGN.md`](docs/DESIGN.md)
- Universul: [`docs/UNIVERS.md`](docs/UNIVERS.md)
- Artă (mărimi, foldere): [`art/README.md`](art/README.md)

## Rulare
Deschide folderul în Godot 4 (Import → `project.godot`) și apasă F5.

Teste logice (fără fereastră):
```bash
godot --headless --script tests/run_tests.gd
```
